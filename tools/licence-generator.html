DeskAsk licence generator

Everything happens inside this page on your computer. Nothing is sent anywhere, and the page can be used offline. Keep your private key file safe: whoever has it can issue licences.

1. Your vendor key

Use the key you already have, or create a pair once. The public key goes into every installation (Licensing:VendorPublicKeyPem in deskask.json). If you change the key, licences signed with the old one stop working.

2. The licence

Limits are optional, written like agents=10, customers=50.

Check a licence

Paste any licence to see what it says. This reads it; it does not check the signature.
