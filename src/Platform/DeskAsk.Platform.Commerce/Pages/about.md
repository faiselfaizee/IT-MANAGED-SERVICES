DeskAsk is IT management software made in Chennai by DamazeTech Solutions (OPC) Private Limited. One platform brings together the tools an IT team uses every day: a service desk run on ITIL practice, asset management, monitoring, Active Directory management, a password vault and backup. Each tool can be bought on its own and grows with the team.

DeskAsk runs in our cloud (SaaS), or on the customer's own Windows servers (on-prem) with a licence key. DamazeTech also provides managed IT services, infrastructure, network and security, Microsoft and cloud services, and is certified to ISO 9001:2015 for quality management (certificate E20260852484).
